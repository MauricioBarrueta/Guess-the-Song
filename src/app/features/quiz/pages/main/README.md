# map()
## Operador de RxJS que transforma los datos emitidos por un Observable antes de que lleguen al consumidor. A diferencia de tap(), sí modifica el valor que continúa por el flujo

-----------------------------------------------------------------------------------------------------------------------------------------------

> [!IMPORTANT]
> ** Dificultad: Difícil **
>
> Este modo obtiene las canciones a partir de los géneros proporcionados por la API pública de Deezer. Debido a las limitaciones de dicha API, algunos géneros pueden devolver canciones poco conocidas o provenientes de recopilaciones, por lo que la experiencia puede variar entre categorías.
>
> ** Nota: ** Esto no afecta el funcionamiento del proyecto y corresponde a una limitación de la fuente de datos utilizada.
